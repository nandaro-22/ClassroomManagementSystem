Help / User Guide

Student Form Viewer v5 • Records + Seat Map

✅ Who can use this system?

This web app supports 3 roles: Admin , Reviewer and Student.

🛠️ Admin Role

Admin can do everything Reviewer can do, plus:
  • View all records (not limited to assigned)
  • Seat Map Admin tools:
    • Add Room
    • Delete Room (Edit Mode OFF only)
    • Add Seat (creates new seat number)
    • Remove Seat (removes last seat only if empty)
    • Edit Mode ON/OFF
    • Assign / clear students per seat

👤 Reviewer Role

What you CAN do
  • Login using Google account (allowlisted)
  • Choose filters (School Year / Term / Course Subject)
  • View student records (assigned records only)
  • Search students
  • View student details + photo + proof of enrollment
  • Add remarks + mark as Done
  • View remarks history
  • Upload evidence (if enabled)
  • Offline mode supported (remarks + done + evidence queue)
What you CANNOT do
  • Add Room
  • Delete Room
  • Add Seat / Remove Seat
  • Turn ON Seat Edit Mode
  • Modify seat assignments

🎓 Student Role

What you CAN do
  • Login using Google account (allowlisted)
  • Access your own profile only
  • View your submitted student information
  • View your photo and enrollment proof
  • View remarks and status
  • View grades and learner development charts
  • Upload evidence for your own record (if enabled)
  • Use secure session with auto login restore
What you CANNOT do
  • View other student records
  • Access student record list
  • Use filters and search
  • Edit remarks
  • Mark record as Done
  • Edit student data fields
  • Access Seat Map
  • Use Seat Map admin tools
  • Add / delete rooms or seats
  • Assign or move seat placements

🪑 Seat Map Rules (Important)

  • Load Room → Select room then click Load Room
  • Edit Mode OFF = View only
  • Edit Mode ON = Admin can edit seats
  • Add Seat adds 1 seat only (seatNo +1)
  • Remove Seat removes last seat only if empty
  • Remove Seat is blocked if last seat has a student assigned

🌐 Offline Mode + Pending Sync (NEW)

This app supports offline mode. If you lose internet connection, the system will store updates locally and sync automatically once online.

✅ What works OFFLINE
  • View already loaded records
  • Save remarks + mark as Done (queued)
  • Seat Map changes (queued if enabled)
  • Upload Evidence (even > 5MB) → saved locally
🔁 Auto Sync when ONLINE returns
  • Pending updates will sync automatically
  • Pending evidence will upload to Google Drive
  • Progress bar shows upload status per item
  • You can Retry or Delete pending items

📤 Evidence Upload (Online vs Offline)

  • If ONLINE: Evidence uploads immediately to Google Drive
  • If OFFLINE: Evidence is stored locally and added to Pending Sync
  • Large files supported: Upload supports files more than 5MB
  • When internet returns, evidence will upload automatically
Tip: Keep the app open during sync so uploads can finish properly.

🟡 Pending Sync Panel

  • Shows pending items waiting to sync/upload
  • Example: “3 evidence waiting to upload”
  • Each item includes progress bar + retry/delete buttons
  • Retry All = sync all pending items
  • Clear All = remove all pending items (use with caution)
Warning: Clearing pending sync will permanently remove offline evidence that has not been uploaded yet.

⚠️ Common Issues

  • Room label stays "-" → click Load Room again or refresh seat map
  • 403 Origin not allowed → add correct Authorized JavaScript Origins in Google Cloud
  • No records found (Reviewer) → reviewer can only view assigned records
  • Evidence upload fails → check internet, then use Retry in Pending Sync
